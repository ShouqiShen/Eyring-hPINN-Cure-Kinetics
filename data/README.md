# Public Data

This directory contains public dummy/sample data only.

Real experimental cure-kinetics CSV files are intentionally excluded from git. To run full experiments with approved datasets, place the real CSV files inside the relevant version folder:

- `benchmarks/v1_arrhenius_hpinn/data/`
- `hpinn_v2_eyring/data/`

See `../docs/data.md` for the expected schema and data policy.
